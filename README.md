# 모아 — 공동생활 할일 관리 MVP

신혼부부, 커플, 자취생, 룸메이트가 함께 쓰는 할일 관리 서비스의 첫 번째 프로토타입입니다.

## 현재 포함된 기능

- 공동 공간(우리 집) 확인
- 할일 추가, 담당자 지정, 완료/되돌리기
- 할일 하루 연기
- 오늘/전체 할일/반복 일정/멤버 화면
- 공동 아이디어 저장, 검색, 보관, 할일 전환
- 일·주·평일·월 반복 일정
- 초대 코드와 초대 링크 생성
- 브라우저 `localStorage` 저장
- 설정 아이콘에서 데모 데이터 초기화

## 실행

`index.html`을 브라우저에서 열면 됩니다. 개발 서버를 사용하려면 프로젝트 폴더에서 다음 중 하나를 실행하세요.

```powershell
node server.mjs
```

또는

```powershell
npx serve .
```

또는

```powershell
python -m http.server 5173
```

현재는 한 브라우저 안에서 동작하는 프로토타입입니다. 다음 단계에서 카카오 로그인, 서버 DB, 실제 초대와 실시간 동기화를 연결합니다.
